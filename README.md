# Описание проекта

Этот проект представляет собой книгу, созданную с использованием `mdbook`. Книга, по-видимому, является учебным пособием или руководством для выполнения дипломной работы.

## Структура проекта

*   `book.toml`: Основной конфигурационный файл для проекта `mdbook`. В нем указываются автор, язык и настройки темы.
*   `src/`: Этот каталог содержит исходные файлы книги.
    *   `SUMMARY.md`: Этот файл определяет структуру книги, выступая в роли оглавления.
    *   `*.md`: Markdown-файлы, содержащие фактическое содержание книги.
*   `book/`: Этот каталог содержит сгенерированную HTML-версию книги, которую можно просматривать в веб-браузере.
*   `theme/`: Этот каталог содержит пользовательские CSS-файлы для стилизации книги.

## Задачи каждой части проекта

*   **`book.toml`**: Управление основными настройками книги.
*   **`src/`**: Хранение и управление исходным контентом книги.
*   **`book/`**: Предоставление готовой к просмотру версии книги.
*   **`theme/`**: Кастомизация внешнего вида книги.

## Команды `mdbook`

*   `mdbook build`: Эта команда собирает книгу, генерируя HTML-вывод в каталоге `book/`.
*   `mdbook serve`: Эта команда запускает локальный веб-сервер для просмотра книги, автоматически пересобирая ее при внесении изменений в исходные файлы.
