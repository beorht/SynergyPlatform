# Этап 4. Глава 2: практическая часть реализации проекта

**Цель этапа**
Описать практическую реализацию проекта по теме ВКР, результаты и оценку.

**Ожидаемый результат**
Готовая Глава 2 с описанием проекта, этапов реализации и итоговой оценкой.

**Входные данные**
1. Оглавление из Этапа 2.
2. Выводы Главы 1.
3. Описание проекта и требований.

**Пошаговое выполнение**
1. Сформулировать постановку задачи практической части.
2. Определить требования и ограничения.
3. Описать план реализации проекта по шагам.
4. Описать используемые технологии, инструменты и методики.
5. Зафиксировать ход работ с промежуточными результатами.
6. Описать тестирование, апробацию или оценку качества.
7. Сформулировать итоговые результаты и сравнить с поставленными задачами.
8. Сформулировать выводы по Главе 2.

**Шаблон структуры Главы 2**
2.1. Постановка задачи и требования
2.2. Проектирование решения
2.3. Реализация проекта
2.4. Оценка результатов
Выводы по Главе 2

**Контроль качества**
1. Описаны конкретные шаги реализации.
2. Есть соответствие между задачами и результатами.
3. Присутствует оценка эффективности или качества.
4. Выводы подтверждаются описанными данными.

**Выходной артефакт**
Раздел «Глава 2» в документе ВКР с подглавами и выводами.
