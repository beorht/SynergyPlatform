# Этап 1. Сбор информации и список литературы (20 источников)

**Цель этапа**
Собрать базу источников по теме ВКР и оформить список литературы, пригодный для дальнейшего цитирования.

**Ожидаемый результат**
Сформирован список из 20 источников с корректными библиографическими сведениями и пометками о полезности.

**Входные данные**
1. Формулировка темы ВКР.
2. Требования кафедры к оформлению списка литературы (если есть).

**Пошаговое выполнение**
1. Определить ключевые слова по теме.
2. Составить расширенный список синонимов и смежных терминов.
3. Найти источники в базах и каталоге библиотеки.
4. Включить в подборку статьи, учебники, методические пособия.
5. Включить нормативные документы и диссертационные материалы (если применимо).
6. Отобрать 20 наиболее релевантных источников.
7. Для каждого источника записать авторов, год, название, издательство или журнал, страницы, DOI или URL.
8. Проверить единый стиль оформления.
9. Сделать краткую пометку, чем источник полезен для ВКР.

**Шаблон списка литературы (пример формата)**
1. Автор А.А. Название книги. Город: Издательство, 2020. 250 с.
2. Автор Б.Б. Название статьи // Название журнала. 2021. № 3. С. 15–28. DOI: ...
3. Организация. Название нормативного документа. Год. URL: ... (дата обращения: ...)

**Контроль качества**
1. Все 20 источников относятся к теме.
2. Не менее 5 источников за последние 5 лет.
3. Есть минимум 1 нормативный документ (если применимо).
4. Нет дубликатов.
5. Оформление единообразное.

**Выходной артефакт**
Файл со списком литературы в конце документа ВКР и отдельный рабочий список с пометками.
