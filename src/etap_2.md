# Этап 2. Написание введения и оглавления

**Цель этапа**
Подготовить введение ВКР и проект оглавления с логичной структурой разделов.

**Ожидаемый результат**
Готовое введение и черновое оглавление по стандарту ВКР.

**Входные данные**
1. Тема ВКР.
2. Список литературы из Этапа 1.
3. Требования к оформлению введения (если есть).

**Пошаговое выполнение**
1. Сформулировать актуальность темы в 1–2 абзацах.
2. Указать объект исследования.
3. Указать предмет исследования.
4. Сформулировать цель исследования.
5. Сформулировать задачи исследования в виде 4–6 пунктов.
6. Сформулировать гипотезу (если требуется по стандарту).
7. Составить оглавление.
8. Проверить, что оглавление соответствует логике цели и задач.

**Шаблон введения**

* Актуальность: ...

* Объект исследования: ...

* Предмет исследования: ...

* Цель исследования: ...

* Задачи исследования:

* Гипотеза: ...

**Шаблон оглавления (пример)**
```
Введение

Глава 1. Теоретическая часть исследования

    1.1. Понятия и ключевые определения
    
    1.2. Обзор подходов и методов по теме
    
    1.3. Анализ существующих решений или практик

Глава 2. Практическая часть реализации проекта

    2.1. Постановка задачи и требования
    2.2. Проектирование решения
    2.3. Реализация и описание работ
    2.4. Оценка результатов

Заключение
Список литературы
Приложения
```

**Контроль качества**
1. Все обязательные элементы введения присутствуют.
2. Цель и задачи согласованы между собой.
3. Оглавление покрывает заявленные задачи.
4. Формулировки краткие и недвусмысленные.

**Выходной артефакт**
Разделы «Введение» и «Оглавление» в документе ВКР.
