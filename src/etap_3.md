# Этап 3. Глава 1: теоретическая часть исследования

**Цель этапа**
Подготовить теоретическую главу с анализом источников и выводами.

**Ожидаемый результат**
Готовая Глава 1 с подглавами, обзором литературы и промежуточными выводами.

**Входные данные**
1. Оглавление из Этапа 2.
2. Список литературы из Этапа 1.
3. Требования к объему теоретической части (если есть).

**Пошаговое выполнение**
1. Уточнить структуру подглав 1.1, 1.2, 1.3.
2. Для каждой подглавы собрать 3–5 ключевых источников.
3. Подготовить краткие конспекты по каждому источнику.
4. Сформулировать определения и основные понятия.
5. Сравнить подходы авторов и выделить общие и различающиеся позиции.
6. Описать существующие модели, методы, классификации по теме.
7. Связать теорию с задачами ВКР.
8. Сформулировать выводы по каждой подглаве.
9. Написать общий вывод по Главе 1.

**Шаблон структуры Главы 1**
1.1. Понятия, термины, определения
1.2. История вопроса и основные подходы
1.3. Анализ современных решений и практик
Выводы по Главе 1

**Контроль качества**
1. В каждой подглаве есть ссылки на источники.
2. Нет пересказа без анализа.
3. Выводы отражают содержание подглав.
4. Текст логично подводит к практической части.

**Выходной артефакт**
Раздел «Глава 1» в документе ВКР с подглавами и выводами.
